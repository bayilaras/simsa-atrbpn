## Isi rilis (`main` `5c61830`)

- **PR #106** (`ab014ba`): menghapus jalur deployment lama dan kode yang tidak dipakai produksi.
  - Dihapus: GCP (Cloud Run, Cloud SQL, terraform), Firebase Auth dan App Check, penyimpanan GCS, Render, image demo beserta mode `metadata-demo`, stack worker persisten, mode lokal Windows, dan `spark/`.
  - Juga dihapus: Swagger, dua rute placeholder tanpa klien, serta dependensi yang tidak terpakai.
  - Startup backend dan build frontend kini menolak nilai env lama (`SIMSA_CLOUD_PLATFORM`, `AUTH_PROVIDER`, `OBJECT_STORAGE_PROVIDER`, `SIMSA_APP_MODE`, dan padanan `VITE_*`).
  - Skema database tidak berubah. Dependabot #95 (edisi Spark) ditutup.
- **PR #107** (`5c61830`): optimasi runtime.
  - **API:** satu bundel esbuild untuk `dist-vercel/app.js`, dan library dokumen (Excel, PDF, QR, email) baru dimuat saat dipakai.
  - **Database:** query per halaman daftar rangkaian berkurang. Bucket siklus hidup dashboard dihitung di SQL. Status baca notifikasi hanya dicari untuk kandidat saat ini.
  - **Katalog klasifikasi/JRA:** dikirim dengan ETag dan divalidasi ulang oleh browser.
  - **Frontend:** total JS gzip 834 → 668 KB. Grafik Laporan pindah ke chart.js. Pencarian Arsip, Dosir, dan Autentikasi di-debounce. Paginasi server dipakai lagi di beberapa daftar.
  - **Perbaikan CI ikutan:** lockfile docs-site (follow-redirects 1.16.2, joi 17.13.9) untuk GHSA-mrwp-f3q8-3g9p dan GHSA-4528-x5fx-h6hg, serta tes migrasi yang memakai tanggal yang sudah lewat.

Migrasi: journal 53 → 54. `0053_list_audit_attachment_indexes` hanya menjalankan `CREATE INDEX IF NOT EXISTS` (lima indeks pada `audit_log`, `file_attachments`, `surat_masuk`, dan `surat_keluar`), jadi aman untuk C64 yang masih berjalan.

- Environment GitHub yang tidak dipakai lagi, `gcp-production-backup` dan `production-backup`, dihapus setelah rilis atas persetujuan pemilik repository.
- `docusaurus.config.js` masih memakai `https://panduan-simsa.vercel.app` sebagai URL kanonik. Alamat itu milik proyek Vercel terpisah yang terakhir dideploy 28 Agustus 2026. Pemilik repository memilih `simsa-atrbpn.vercel.app` sebagai alamat resmi; perubahannya diajukan di #117 dan berlaku pada publikasi situs panduan berikutnya.
