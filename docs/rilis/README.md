# Laporan rilis produksi

Setiap rilis produksi dicatat sebagai `HASIL_RILIS_<label>_<tanggal>.md` di folder ini, mengikuti langkah 7 [prosedur rilis](../RUNBOOK_KREDENSIAL_DATABASE.md#prosedur-rilis). Label `Cxx_Cyy` berarti nomor kandidat backend dan frontend; satu nomor berarti hanya satu proyek yang dirilis. Laporan seri C dibuka dengan rujukan ke laporan sebelumnya.

Rilis integrasi surat masuk dan keluar (P0–P5) juga menyimpan bukti pre-flight (`HASIL_PREFLIGHT_INTEGRASI_SURAT_P0_2026-10-03.md`), laporan tahap AB dan C, serta uji asap (`HASIL_UJI_ASAP_INTEGRASI_SURAT_2026-10-04.md`) yang dirujuk oleh [lembar persetujuan](../SIGN_OFF_RILIS_INTEGRASI_SURAT.md).
