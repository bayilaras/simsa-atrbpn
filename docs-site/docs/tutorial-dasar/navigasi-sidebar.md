# 🧭 Navigasi Sidebar

Sidebar adalah menu navigasi utama di sisi kiri layar SIMSA. Dari sini kamu bisa mengakses semua fitur yang tersedia.

---

## Tampilan Sidebar

:::tip Tampilan Sidebar
Sidebar menampilkan menu navigasi yang dikelompokkan sebagai berikut:

**UTAMA**
- 📊 Dashboard

**MANAJEMEN SURAT**
- 📧 Surat → 📨 Surat Masuk, 📤 Surat Keluar
- 🔄 Distribusi

**SIKLUS HIDUP ARSIP**
- 🗂️ Arsip Aktif → Arsip Surat Masuk, Arsip Surat Keluar
- 📁 Pemberkasan (Dosir)
- ⏱️ Jadwal Retensi
- 📊 Manajemen Retensi
- ✂️ Penyusutan

**LAYANAN & FISIK**
- 📋 Layanan Arsip
- 🔄 Peminjaman
- 📍 Lokasi Simpan 🔒
- 🛡️ Arsip Vital 🔒
- 🔐 Arsip Terjaga 🔒

**MEDIA & AUTENTIKASI**
- 💾 Arsip Elektronik
- 🛡️ Autentikasi
- 🔗 Tunjuk Silang

**ADMINISTRASI**
- 📊 Laporan
- 📝 Audit Log
- 👥 User Management 🔒
- 📂 Master Data 🔒 → Klasifikasi Arsip, Template Surat
- ⚙️ Settings 🔒

*Menu dengan 🔒 hanya tersedia untuk role tertentu.*
:::

## Cara Menggunakan Sidebar

### Membuka Menu

1. **Menu biasa** — Klik langsung pada nama menu, kamu akan diarahkan ke halaman tersebut.
2. **Menu dengan sub-menu** (ada ikon ▼) — Klik untuk membuka/tutup sub-menu, lalu klik sub-menu yang diinginkan.

### Melipat Sidebar

- Klik ikon **hamburger** (☰) di bagian atas untuk **melipat** sidebar.
- Sidebar yang dilipat hanya menampilkan **ikon** saja, tanpa teks.
- Hover mouse di atas ikon untuk melihat **tooltip** nama menu.
- Klik ikon hamburger lagi untuk **membuka** kembali sidebar.

---

## Menu dengan 🔒 (Khusus Admin)

Menu yang ditandai 🔒 **hanya tersedia** untuk pengguna dengan role tertentu:

| Menu | Tersedia Untuk |
|------|----------------|
| Lokasi Simpan | Admin Dirjen, Admin Sesditjen, Super Admin |
| Arsip Vital | Admin Dirjen, Admin Sesditjen, Super Admin |
| Arsip Terjaga | Admin Dirjen, Admin Sesditjen, Super Admin |
| User Management | Super Admin saja |
| Master Data | Admin Dirjen, Admin Sesditjen, Super Admin |
| Settings | Super Admin saja |

> 💡 Jika kamu tidak melihat menu tertentu di sidebar, artinya role kamu tidak memiliki akses ke menu tersebut.

---

## Indikator Menu Aktif

- Menu yang sedang **aktif** (halaman yang sedang dibuka) akan ditandai dengan **highlight** berwarna.
- Menu yang memiliki **notifikasi baru** akan menampilkan **titik biru kecil** yang berkedip di samping nama menu.
