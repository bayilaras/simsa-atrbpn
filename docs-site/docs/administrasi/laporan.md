# 📊 Laporan

Panduan membuat dan mengekspor laporan di SIMSA.

---

## Apa Itu Halaman Laporan?

Halaman laporan menampilkan **data statistik dan ringkasan** yang bisa diunduh dalam format **PDF** atau **Excel**. Laporan ini berguna untuk keperluan pelaporan internal dan audit.

---

## Jenis Laporan yang Tersedia

| Laporan | Keterangan |
|---------|------------|
| **Laporan Surat Masuk** | Rekap surat masuk per periode |
| **Laporan Surat Keluar** | Rekap surat keluar per periode |
| **Laporan Arsip** | Ringkasan arsip per klasifikasi |
| **Laporan Retensi** | Daftar arsip yang memasuki masa retensi |
| **Laporan Distribusi** | Rekap distribusi surat antar unit |
| **Laporan Peminjaman** | Rekap peminjaman arsip fisik |

---

## Cara Membuat Laporan

### Langkah 1: Buka Menu Laporan
Di sidebar, klik **Laporan** di bawah **Administrasi**.

### Langkah 2: Pilih Jenis Laporan
Pilih jenis laporan dari dropdown atau tab yang tersedia.

### Langkah 3: Atur Filter

| Filter | Keterangan |
|--------|------------|
| **Periode** | Pilih rentang tanggal (dari - sampai) |
| **Unit Kerja** | Pilih unit kerja tertentu (atau semua) |
| **Klasifikasi** | Filter berdasarkan kode klasifikasi |
| **Status** | Filter berdasarkan status |

### Langkah 4: Generate Laporan
Klik **"Generate"** atau **"Tampilkan"** untuk melihat hasil.

### Langkah 5: Ekspor

| Tombol | Format |
|--------|--------|
| 📄 **Export PDF** | Laporan dalam format PDF |
| 📊 **Export Excel** | Laporan dalam format XLSX |
